# go-to-market

Finding accounts, researching them, and writing to people. Sales, customer success and marketing work, none of it needing a terminal.

One rule runs through all of them: every fact that reaches a prospect or a customer carries a source and a date, or it does not get sent. Invented familiarity is how AI-written outreach fails, and it fails expensively, because the reader is the one person who can check the claim instantly.

**Model-invoked**

- [`setup-gtm-workflow`](./setup-gtm-workflow/SKILL.md) records the team’s existing stack and rules, CRM, stages, sequencer, suppression, approvals, into one profile the other four read. Run it once per team
- [`icp-lead-generation`](./icp-lead-generation/SKILL.md) finds target accounts against a profile the team already trusts, with filters that can come back false and a citation per row
- [`account-enrichment`](./account-enrichment/SKILL.md) builds a one-page dossier for one decision, checking the CRM, inbox and call notes before the open web
- [`cold-outreach`](./cold-outreach/SKILL.md) writes a first touch on one dated fact, with a single small ask and a compliance floor
- [`proactive-customer-outreach`](./proactive-customer-outreach/SKILL.md) drafts check-ins and milestone notes in the team's own voice, and refuses to send cheerfully into an open escalation

Run `setup-gtm-workflow` once, then the rest chain in that order, and each one works alone. Enrichment is the one that pays for itself fastest, because it is what stops the other two inventing things.
