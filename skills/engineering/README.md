# engineering

Daily code work.

**User-invoked**

- [`setup-team-conventions`](./setup-team-conventions/SKILL.md) — run first in a team repo: detect the forge, tracker, branch/commit conventions, verify commands and review rules, and record them in `docs/agents/`
- [`grill-with-docs`](./grill-with-docs/SKILL.md) — grilling session that writes ADRs and a glossary as it goes
- [`implement`](./implement/SKILL.md) — build from a spec or tickets; scope discipline, evidence before done, never commits for you
- [`improve-codebase-architecture`](./improve-codebase-architecture/SKILL.md) — scan for deepening opportunities, report visually, grill the one you pick

**Model-invoked**

- [`browser-testing`](./browser-testing/SKILL.md) — verify against a real running page; drive the browser yourself rather than asking someone to open DevTools
- [`code-review-and-quality`](./code-review-and-quality/SKILL.md) — review across five axes, verify each finding before reporting it, rank everything, keep comments to three to five lines
- [`code-simplification`](./code-simplification/SKILL.md) — reduce complexity without changing behaviour, working down a ladder from "does this need to exist"
- [`codebase-design`](./codebase-design/SKILL.md) — vocabulary for deep modules: module, interface, depth, seam, adapter, leverage, locality
- [`context-engineering`](./context-engineering/SKILL.md) — curate what the agent sees and when, so quality does not decay as a session grows
- [`diagnosing-bugs`](./diagnosing-bugs/SKILL.md) — reproduce with the reporter's exact steps, build a tight loop, work the phases
- [`domain-modeling`](./domain-modeling/SKILL.md) — keep the glossary and ADRs current as decisions land
- [`efficient-fable`](./efficient-fable/SKILL.md) — Fable orchestrates; cheap agents gather evidence, codex implements on a separate bill when it is available
- [`planning-and-task-breakdown`](./planning-and-task-breakdown/SKILL.md) — dependency graph, vertical slices, each task owning its paths and carrying its own acceptance check
- [`tdd`](./tdd/SKILL.md) — red → green at pre-agreed seams, with evidence
